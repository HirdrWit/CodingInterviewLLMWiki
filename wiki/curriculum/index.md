order — it is deliberately built so each topic leans on the last.

**Rule: a topic is not done when its problems are solved once.** It's done when
every problem in it has been solved *cold* on a re-attempt. See the ladder in

## The loop

```
lesson <topic>  →  read, watch, ask questions  →  say "ready"
     ↓
timed <problem>  →  30 minutes, alone, no hints
     ↓
debrief  →  what worked / what broke / the pattern / next three fixes
     ↓
write-up in wiki/problems/  +  re-attempt scheduled in review-queue
     ↓
cold re-attempt  →  pass: promote.  fail: back in the queue, no shame.
```
