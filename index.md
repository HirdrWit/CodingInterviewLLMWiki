## How to use this

Talk to Claude in this directory and name an operation:

| Say | It does |
|---|---|
| `ingest <url / file / paste>` | Files the raw source, distills it into the wiki, rewires links |
| `query <question>` | Answers from the wiki with citations; promotes good answers to pages |
| `lesson <topic>` | Teaches the fundamentals, then hands over materials — no solutions |
| `timed <problem>` | Starts the 30-minute box. No hints while it runs. |
| `debrief` | Reviews my attempt: what worked, what broke, the pattern, next fixes |
| `review` | Surfaces what's due for a cold re-attempt |
| `lint` | Finds contradictions, stale claims, orphans, unproven statuses |
| `plan` | Proposes next week's work from my gaps |

The rules it follows are in [[CLAUDE|CLAUDE.md]].
