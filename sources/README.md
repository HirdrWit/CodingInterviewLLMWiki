# sources/

**Raw and immutable.** Articles, problem statements, book chapters, course notes,
transcripts, screenshots, job descriptions — dropped in as they came.

Rules:
- Never edit a file here. Never delete one.
- Never link to a source as if it were a wiki page — the wiki cites sources,
  not the other way around.
- Name files `YYYY-MM-DD-short-slug.ext` so provenance is obvious at a glance.

To use one: drop it in and say `ingest <filename>`. The distilled version lands
in `wiki/`; this copy stays here so a claim can always be traced back.
